# HTML Basics

## What is HTML?

HTML stands for HyperText Markup Language.

HTML is a markup language used to structure content on a webpage.

It is not a programming language.

## Three Core Technologies

### HTML
Used for the structure of a webpage.

### CSS
Used for styling, presentation and layout.

### JavaScript
Used to add behavior and functionality.

## Tools

- Visual Studio Code
- Google Chrome
- Live Server extension

## Key Points

- HTML provides the structure of a webpage.
- CSS controls the appearance.
- JavaScript provides interactivity.
- HTML5 is the modern major version of HTML.
