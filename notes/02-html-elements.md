# HTML Elements

## Common HTML elements

- Headings: `h1` to `h6`
- Paragraphs: `p`
- Links: `a`
- Images: `img`
- Lists: `ul`, `ol`, `li`
- Tables: `table`, `tr`, `td`, `th`
- Forms: `form`, `input`, `label`, `button`, `select`, `textarea`

## Attributes

Elements can have attributes to provide additional information, e.g., `src`, `alt`, `href`, `class`, `id`.

## Void elements

Some elements do not have closing tags: `img`, `br`, `hr`, `meta`, `input`.
