# HTML Document Structure

## Basic skeleton

```
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Document Title</title>
</head>
<body>
  <!-- Page content -->
</body>
</html>
```

## Head vs Body

- `head`: metadata, links to stylesheets, scripts, titles, meta tags.
- `body`: visible content rendered by the browser.
