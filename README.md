A practical frontend learning repository covering the foundations of web development before moving into Angular.

## Repository Structure

- `html/` - Small HTML examples covering document structure, headings, formatting, forms, lists, tables, images, and semantic tags.
- `css/` - CSS exercises and styling practice.
- `javascript/` - JavaScript exercises and examples.
- `notes/` - Study notes covering HTML basics, elements, document structure, and formatting.

## Getting Started

1. Open this repository in Visual Studio Code.
2. Open any example such as `html/01-basic-structure/index.html`.
3. Open the file in a browser, or use the **Live Server** extension for automatic refresh while editing.

No build step or package installation is currently required for the HTML examples.

## Suggested Learning Path

1. Read the related notes in `notes/`.
2. Open the matching example in `html/`.
3. Modify the markup and observe the result in a browser.
4. Continue with CSS and JavaScript practice as those sections grow.

## Topics Covered

- HTML document structure
- Headings and text formatting
- Forms
- Lists and tables
- Images
- Semantic HTML
- CSS fundamentals
- JavaScript fundamentals
